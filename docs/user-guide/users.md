# Manage users

Administrators can open **Users** to control access to the management page.

## Roles

- **Administrator** — Can operate the wall and change sources, screens, tours, and users.
- **User** — Can view the wall and its status but cannot change protected settings.

Give administrator access only to people who maintain the wall.

## Add a user

1. Open **Users**.
2. Select **Add User**.
3. Enter a username and a temporary password of at least eight characters.
4. Choose the role.
5. Select **Create**.
6. Give the temporary credentials to the person through an approved secure method.

The new user must choose a new password on first sign-in.

## Change a role

Open the three-dot menu beside the user and select **Edit role**. You cannot change your own role.

## Delete a user

Open the three-dot menu beside the user, select **Delete**, and confirm. You cannot delete your own account. Deleting an account does not change the wall’s sources or display setup.

## Password safety

- Do not share the built-in `admin` account.
- Use a unique password and store it in your organization’s password manager.
- Do not send passwords or YouTube cookie files in ordinary email or chat.
- Remove accounts when a person no longer needs access.

There is currently no self-service password reset in the management page. If a person loses access, an administrator should create a replacement account or contact the system owner.
